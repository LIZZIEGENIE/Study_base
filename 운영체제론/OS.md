# 운영체제론


## Chap 1. 운영체제(Operating System)
- 운영체제 - 컴퓨터 자원을 할당 및 관리하는 **시스템 소프트웨어**
### 분류 - ***응답시간*** 과 ***데이터 입력 방식*** 에 따른 분류
- 일괄처리 시스템 (batch processing system)
- 다중 프로그래밍 시스템 (multi-programming system)
- 시분할 시스템 (time-sharing system)
- 다중 처리 시스템 (multi-processing system)
    - 강결합 시스템, 한 컴퓨터 안에 여러 CPU·코어. 보통 메모리 등을 공유하므로 이미지에서는 강결합으로 연결
- 실시간 처리 시스템 (real-time processing system)
- 분산 처리 시스템 (distributed processing system)
    - 약결합 시스템, 독립된 여러 컴퓨터가 네트워크로 협력. 각자 메모리를 가지므로 약결합으로 연결

<br>

| 종류 | 핵심 개념 | 기억할 장면 |
|---|---|---|
| **일괄처리** | 작업을 **모아서 한꺼번에** 처리 | 한 달 치 급여 계산을 모아 실행 |
| **다중 프로그래밍** | 한 작업이 입출력을 기다리면 **다른 작업으로 CPU를 계속 사용** | A가 디스크를 기다리는 동안 B 실행 |
| **시분할** | CPU 시간을 **짧게 나눠 번갈아** 배정 | 여러 사용자가 각자 즉시 반응을 받는 것처럼 사용 |
| **다중 처리** | CPU·코어를 **여러 개 써서 실제로 동시에** 처리 | 코어 1은 A, 코어 2는 B 실행 |
| **실시간 처리** | 정해진 **시간 안에 반드시** 처리 | 자동차 제동 제어가 기한 안에 반응 |
| **분산 처리** | **여러 컴퓨터가 연결되어** 작업을 나눠 처리 | 여러 서버가 계산을 분담 |

<br>

- **다중 프로그래밍은 ‘대기 시간을 활용’, 시분할은 ‘시간을 쪼개 배정’, 다중 처리는 ‘CPU를 늘림’**

- 간단하게
    - 일괄 = 모아서 / 다중 프로그래밍 = 기다릴 때 다른 일 / 시분할 = 조금씩 번갈아 / 다중 처리 = 여러 CPU / 실시간 = 기한 안에 / 분산 = 여러 컴퓨터

<br>

| 구분 | 다중 프로그래밍 시스템 | 다중 처리 시스템 |
|---|---|---|
| 핵심 | 여러 프로그램을 준비해 두고, 실행할 수 있는 프로그램에 CPU를 배정 | 여러 CPU·코어가 작업을 나눠 실행 |
| 주된 목적 | 입출력 대기 중에도 CPU가 일하도록 활용률을 높임 | 실제 병렬 실행으로 처리 능력을 높임 |
| CPU 하나로 가능? | **가능** | **불가능** — 처리 장치가 여러 개 필요 |
| A와 B의 실행 | CPU 하나라면 같은 순간에는 하나만 실행 | 서로 다른 코어에서 같은 순간에 실행 가능 |

## Chap 2. 프로세스와 스레드
### 프로세스(process) - 프로그램에 대한 인스턴스
- 실행 중인 프로그램. 운영체제에서 **작업의 기본 단위**. 반드시 한 개의 PCB와 연결됨. **비동기적인 행위**를 일으키는 주체 *('비동기적인 행위'란 각 프로세스가 다른 프로세스와 항상 발맞춰 실행되지 않고, 각자의 진행 샅애에 따라 실행하고 대기를 한다는 의미)*.

### PCB(Process Control Block), 프로세스 제어 블록
- 프로세스에 대한 중요한 정보 제공하여 프로세스를 정의해주는 데이터 블록  (프로세스를 제어하고 관리하는 데 필요한 정보를 담은 자료구조. 운영체제가 PCB를 읽고 갱신할 수 있도록 정보를 담아놓음)
- 프로세스를 생성할 때 만들어지며 프로세스가 종료되면 같이 삭제됨

### 프로세스 생성 과정
1. 프로세스 식별자(PID) 할당
    - 새 프로세스를 위한 고유 식별자인 PID를 할당함
2. 주소 공간과 PCB 할당
    - 새 프로세스를 위한 주소 공간과 프로세스 제어블록(PCB)을 할당함
3. PCB 초기화
    - 새 프로세스의 PCB를 초기화 함
4. 준비 큐에 프로세스를 삽입
    - 새 프로세스를 스케줄링 큐의 준비 또는 준비/보류 리스트에 연결

### 프로세스의 메모리 구조
1. 스택(stack) - **데이터를 일시적으로 저장**
    - 지역변수, 호출한 함수의 반환 주소(복귀 주소), 반환 값, 매개변수 등에 사용함
2. 힙(heap) - **사용자가 동적으로 할당 및 해제**
    - 프로그램 실행 중 동적으로 메모리를 할당하기 위해 사용함
3. 데이터(data)
    - 전역변수(global)나 정적변수(static)를 할당하기 위해 사용함
4. 코드(code)
    - 컴파일한 프로그램의 코드나 명령어 등이 저장됨
